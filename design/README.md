# Bhasha Kids design prototypes

Interactive iPad and mobile prototypes exported from the Claude Design project.

- `Bhasha Kids Tablet.dc.html` - iPad landscape prototype
- `Bhasha Kids Mobile.dc.html` - phone prototype
- `*-frame.jsx`, `support.js`, `image-slot.js` - device frames and runtime used by the prototypes
- `github.md` - sync log between the design project and this repo

The prototypes load images, video and the playable game pages from `../public/`,
so keep this folder next to `public/`. They are design references, not part of the Next.js app.
